Research Work

📄 ICADCML 2026

"Satellite Image Analysis using RAG & Vision-Language Models (VLMs)"

This project presents a multi-modal AI system for satellite image analysis that integrates visual understanding with intelligent question answering. A BLIP2 captioning model, fine-tuned on the RSICD dataset, is utilized to generate domain-specific descriptions of satellite scenes. For land cover detection, HSV-based segmentation quantifies vegetation and identifies geographical classes such as buildings, roads, and water bodies. CLIP embeddings are matched against a vector database created from the EarthVQA dataset to enable retrieval-augmented generation (RAG), where the Gemini LLM uses the generated caption, quantitative land cover data, and retrieved context to answer user questions clearly.
